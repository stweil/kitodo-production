# Korrekturmeldungen

Korrekturmeldungen dienen dazu, Vorgänge bei Unregelmäßigkeiten zurück an die vorherige Bearbeitungsstation zu senden. Wenn die Unregelmäßigkeit behoben ist, kann die Korrekturmeldung abgeschlossen werden. Das Verfahren hat den Vorteil, dass alle Schritte protokolliert werden, was für Fehleranalysen sehr hilfreich ist.

Korrekturmeldungen können ausgelöst werden, wenn eine Aufgabe übernommen wird; auch im Metadateneditor ist das Auslösen einer Korrekturmeldung möglich.

## Korrekturmeldung an vorherige Station senden

Soll ein Vorgang wegen einer Korrektur an die vorherige Station gesendet werden, muss **Korrekturmeldung an vorherige Station senden** betätigt werden. Danach ist unter *Zurück zu Aufgabe* der jeweilige Arbeitsschritt auszuwählen; optional kann die Beschreibung des Problems/Fehlers ergänzt werden.

Danach findet der Empfänger der Korrekturmeldung den Vorgang wieder in seinen Aufgaben und kann die Korrektur durchführen.

## Problemlösung an nachfolgende Station senden

Nach der Korrektur wird mit **Problemlösung an nachfolgende Station senden** die Korrekturmeldung abgeschlossen. Unter *Senden an Arbeitsschritt* ist der jeweilige Arbeitsschritt auszuwählen; optional kann die Beschreibung der Lösung ergänzt werden.

Danach findet der Empfänger den Vorgang wieder in seinen Aufgaben und kann die Bearbeitung fortsetzen.

## Hinweise

* Der gesamte Ablauf (wer wann eine Korrekturmeldung gesendet bzw. gelöst hat) wird protokolliert.
* Ob und wie Korrekturmeldungen verwendet werden können, ist je Aufgabe im Workflow konfigurierbar (Aufgabeneigenschaften *Korrektur* und *Wiederholung bei Korrektur*).
