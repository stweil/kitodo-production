# Paginierung

Die Paginierung (Vergabe der Seitenzählung) wird im Metadateneditor ausgeführt: Wählen Sie dort den Punkt *Paginierung* aus und klappen Sie anschließend das Fenster *Metadaten* auf.

## Optionen

**Paginierung**

* arabisch
* römisch
* unnummeriert
* Freitext
* alphabetisch (ab Version 4.0)
* für Fortgeschrittene

**Paginierungsstartwert** – z. B. `5`, wenn die Seitenzählung erst mit 5 beginnen soll.

**Paginierungsumfang**

* *Nur die markierten Seiten*: Zuweisung der Zählung auf bestimmte Images
* *Ab der ersten markierten Seite*: Zuweisung der Zählung auf alle Images ab einem bestimmten Image

**Zählung**

* Seitenzählung
* Spaltenzählung
* Blattzählung
* Blattzählung recto-verso
* Blattzählung verso-recto (ab Version 4.0)
* Seitenzählung recto-verso
* Seitenzählung Doppelseiten

**Fingierte Paginierung** – die ausgewählte Zählung wird in eckigen Klammern dargestellt, wenn die Seite physisch nicht gezählt ist.

## Seitenauswahl

Wenn der *Paginierungsumfang* auf *Nur die markierten Seiten* gestellt ist, werden nur die markierten Seiten paginiert. Die Seiten können auf verschiedenen Wegen ausgewählt werden:

* Einzelne Seiten durch Linksklick im Strukturbaum oder in der Galerie
* `Strg + Linksklick` fügt die angeklickte Seite der bisherigen Auswahl hinzu bzw. entfernt sie wieder
* `Umschalttaste (Shift) + Linksklick` wählt alle Seiten zwischen der zuerst und der zuletzt angeklickten Seite aus (inklusive beider)
* Über das Kontextmenü im Strukturbaum: *Zugewiesene Medien auswählen* wählt alle Seiten des entsprechenden Strukturelements aus (ab Version 4.0)

Seiten mit einer unterbrochenen Zählung (z. B. ungezählte Blätter im Haupttext) können durch mehrere Paginierungsvorgänge mit unterschiedlichen Startwerten vergiben werden.
